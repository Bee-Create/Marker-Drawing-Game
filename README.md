# Marker Drawing Game
<h3>View Live Page</h3>
Visit <a href="https://bee-create.github.io/Marker-Drawing-Game/">my live page</a> to see the code perform.<br>
<h3>Purpose of This Project</h3>
This coding project allows you to select from three markers to draw on a canvas. You will be able to select your color, adjust brush sizing, and clear the canvas.<br>
<h3>Tools & Tech Used</h3>
<UL>
  <li>JavaScript</li>
  <li>CSS</li>

  <li>Computer</li>
</UL><br>

<h3>Important Information & Reuse Policy</h3>
This is a CSS project (from freecodecamp.org) that I added JavaScript to in order to make it interactive.<br>
Reuse is welcome, as long as you give credit to "freecodecamp" as well.
<h3>Instructions</h3>
Click or tap a marker color, slide the adjuster to select your brush size, and start drawing on the canvas below!<br>
Clear the canvas to start a new drawing.
